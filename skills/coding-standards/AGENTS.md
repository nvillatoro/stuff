## Storybook

- Storybook files must use the `.stories.{ext}` filename pattern.
- Every React component must have a corresponding colocated Storybook story; create it if missing and keep it up to date with the component's behavior and supported states.
- Every React component must have a corresponding colocated Storybook documentation file in `.mdx` format; create it if missing and keep it up to date with the component's behavior and supported states.
